# Mudança de Endereço — SIP

> Base FICTÍCIA, criada para testar o esclarecimento pelas bases (script `clarification-test-kbs.ts`). Não é procedimento oficial.

## 1. Objetivo
Orientar a mudança de endereço do tronco SIP (voz corporativa sobre IP) de clientes empresariais.

## 2. Requisitos no novo endereço
- Link de dados ativo no novo endereço com capacidade para o número de canais contratados.
- PABX do cliente compatível e acessível pela equipe técnica do cliente.

## 3. Numeração
- Mesma área local: a numeração (ramais e DDR) é mantida.
- Outra área local: a numeração não pode ser levada; é preciso contratar nova faixa de números na nova área.

## 4. Documentos
- Pedido formal do gestor do contrato.
- Endereço do novo local e contato do responsável pelo PABX.

## 5. Passo a passo
1. Confirmar o link de dados no novo endereço (seção 2).
2. Verificar a área local da numeração (seção 3).
3. Registrar a mudança e agendar a janela de migração com o responsável pelo PABX.
4. Na janela, a equipe técnica reconfigura o tronco; o cliente reconfigura o PABX.

## 6. Prazo
Até 15 dias úteis após o pedido formal.
