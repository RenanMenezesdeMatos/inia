# Mudança de Endereço — Linha FWT

> Base FICTÍCIA, criada para testar o esclarecimento pelas bases (script `clarification-test-kbs.ts`). Não é procedimento oficial.

## 1. Objetivo
Orientar a mudança de endereço da linha FWT (telefone fixo sem fio, que funciona pela rede celular com um aparelho de mesa).

## 2. Cobertura celular
A mudança só é possível se o novo endereço tiver cobertura celular adequada. Consulte o mapa de cobertura antes de registrar.

## 3. Documentos
- Comprovante do novo endereço em nome do titular (até 90 dias).

## 4. Endereço de emergência
O endereço cadastral da linha precisa ser atualizado no mesmo atendimento: ele é usado para chamadas de emergência.

## 5. Passo a passo
1. Verificar a cobertura no novo endereço (seção 2).
2. Atualizar o endereço cadastral (seção 4).
3. Orientar o cliente a levar o aparelho FWT e ligá-lo no novo endereço.

## 6. Prazo
Imediato: a linha funciona no novo endereço assim que o cadastro é atualizado e o aparelho é ligado.

## 7. Sem cobertura
Sem cobertura celular no novo endereço, oferecer a linha básica (ver base própria), quando houver viabilidade de rede.
