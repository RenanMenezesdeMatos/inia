# Jeito de atender e encerramento

## 1. Objetivo
Definir como o atendimento começa, como o cliente é tratado e como a ligação termina, em qualquer assunto.

## 2. Abertura
O operador deve dizer o nome da empresa e o próprio nome na saudação.
Exemplo: "Exemplo Telecom, bom dia, meu nome é Carla. Com quem eu falo?"

## 3. Tratamento
O operador deve chamar o cliente pelo nome pelo menos uma vez durante o atendimento.
Evitar:
- interromper o cliente;
- "Não é comigo."

## 4. Encerramento
Antes de encerrar:
- perguntar se o cliente tem mais alguma dúvida;
- agradecer o contato.
