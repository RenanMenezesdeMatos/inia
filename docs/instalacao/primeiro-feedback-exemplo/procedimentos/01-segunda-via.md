# Procedimento Operacional — Segunda via

## 1. Objetivo
Orientar o envio da segunda via da conta ao cliente.

## 2. Validação do titular
O operador deve confirmar o nome completo e a data de nascimento do titular antes de informar qualquer dado da conta.

## 3. Envio da segunda via
O operador deve perguntar por qual canal o cliente prefere receber a segunda via: e-mail cadastrado ou SMS.
O operador deve confirmar o e-mail ou o celular cadastrado antes de enviar.
O operador deve informar que a segunda via chega em até 10 minutos.
Exemplo: "Enviei a segunda via para o seu e-mail; ela chega em até dez minutos."

## 4. Código de barras
Quando o cliente pedir, o operador pode ditar o código de barras.

## 5. Encerramento
Antes de encerrar, informar:
- o protocolo do atendimento;
- o prazo de chegada da segunda via.
